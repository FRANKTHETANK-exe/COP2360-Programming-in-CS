# COP2360 Programming in C#

C# console and Windows Forms assignments for COP2360.

| Project | Description |
| --- | --- |
| [Movies](A01-Movies/) | Displays favorite movies and television shows. |
| [Fish Weights](A02-FishWeights/) | Calculates an average fish weight. |
| [Slugs](A03-Slugs/) | Windows Forms calculator for counts from five locations. |
| [Sign Pricing](A04-SignPricing/) | Prices signs by height. |
| [Fish Sizes](A05-FishSizes/) | Collects sizes and calculates a total and average. |
| [Lottery Numbers](A06-LotteryNumbers/) | Checks a number against a sample lottery drawing. |
| [Stork Weight](A07-StorkWeight/) | Converts a height to an estimated weight. |
| [Salary Raises](A08-SalaryRaises/) | Calculates percentage and fixed-amount raises. |
| [Inductees](A09-Inductees/) | Stores and displays artist induction records. |
| [Scooters](A10-Scooters/) | Models manual and electric scooters using inheritance. |
| [Llama Rental](A12-LlamaRental/) | Windows Forms code for rental pricing. |

## Run

Movies requires the .NET 9 SDK:

```sh
dotnet run --project A01-Movies/MoviesApp.csproj
```

The other console exercises each contain a standalone `Program.cs`; add each file to a separate C# console project.

Open `A03-Slugs/slugs1.sln` in Visual Studio on Windows with .NET Framework 4.7.2 support.

Llama Rental requires its missing designer and project files to build.
